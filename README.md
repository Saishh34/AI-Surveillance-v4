# AI Surveillance System

> Real-time AI-powered multi-camera surveillance system with person detection, intrusion monitoring, loitering detection, automated recording, Telegram alerts, activity logging, and a web-based monitoring dashboard.

<p align="center">

**YOLO • OpenCV • Python • Flask • SQLite • JavaScript**

</p>

---

## 🚨 Overview

AI Surveillance System is a real-time computer vision platform designed to monitor multiple cameras and automatically detect potentially suspicious activity.

The system combines AI-based object detection, object tracking, intrusion-zone monitoring, loitering detection, automated video recording, remote Telegram alerts, persistent activity logging, and a real-time web dashboard into a single surveillance pipeline.

It is designed to run locally on a user's computer using available cameras such as a laptop webcam or USB camera.
